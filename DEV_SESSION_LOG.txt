USER INSTRUCTION:
  "Fix the slot generation in the digital drag-and-drop screen. Currently
  there are not enough slots to input the answer (e.g. '9-5=' only provides
  4 slots, but it needs 5 to accommodate the answer '4'). The number of
  DragTarget slots must dynamically match the total character count of the
  complete equation (operands + operator + equals sign + answer).

  ABSOLUTE CRITICAL DIRECTIVE:
  DO NOT touch yolo_service.dart, camera_screen.dart, or course_provider.dart.
  ONLY modify the UI generation logic inside lib/screens/digital_caps_screen.dart.

  Steps:
  1. Extract full expected equation from current level.
  2. Strip whitespace (e.g. '14 + 25 = 39' → '14+25=39').
  3. Use string length as slot count.
  4. Replace hardcoded DragTarget list with List.generate(...).
  5. Wrap slots in a Wrap widget."

ROOT CAUSE:
  The _setupSlots() method split the equation by spaces:
    final parts = widget.targetLevel!.expectedEquation.split(' ');
    _requiredSlots = parts.length;
  For "24 + 7 = 31", this gave 5 tokens ["24", "+", "7", "=", "31"],
  so only 5 slots were created. But each CHARACTER needs its own slot,
  so "24+7=31" → 7 chars → 7 slots required.

CHANGES MADE to lib/screens/digital_caps_screen.dart (_setupSlots method):
  BEFORE:
    void _setupSlots() {
      if (widget.targetLevel != null) {
        // e.g., "1 + 2 = 3" -> 5 parts
        final parts = widget.targetLevel!.expectedEquation.split(' ');
        _requiredSlots = parts.length;
      } else {
        _requiredSlots = 5;
      }
      _slots = List.filled(_requiredSlots, null);
    }

  AFTER:
    void _setupSlots() {
      if (widget.targetLevel != null) {
        // Strip all whitespace to get the raw character count.
        // e.g., "24 + 7 = 31" -> "24+7=31" -> 7 slots
        final stripped = widget.targetLevel!.expectedEquation.replaceAll(' ', '');
        _requiredSlots = stripped.length;
      } else {
        _requiredSlots = 5; // Default for practice mode
      }
      _slots = List.filled(_requiredSlots, null);
    }

  So the label names must match exactly — this fix is critical for the
  YOLO cap detection to work correctly.
